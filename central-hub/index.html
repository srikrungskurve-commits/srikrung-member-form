🧩 SRIKRUNG CENTRAL HUB

ตัวอย่างช่องเสียบจิ๊กซอว์: สองประตู → ตัวตนกลาง → บริการ

① ประตู LINE Follow

จำลองการรับ LINE User ID โดยไม่ถือว่าเข้าสู่ระบบสำเร็จ

② ประตู Central Login

จำลองการยืนยันตัวตนด้วยบัญชีทดสอบเท่านั้น

③ ตัวตนกลาง

ยังไม่เข้าสู่ระบบ

บัญชีเดียว: LINE Follow สร้างข้อมูลเบื้องต้น / Login เปิดสิทธิ์จำลอง; ในระบบจริงต้องพิสูจน์การผูกบัญชีฝั่งเซิร์ฟเวอร์

④ Central Dashboard / ช่องเสียบโมดูล

เพิ่มโมดูลผ่านรายการ Registry โดยไม่แก้ระบบ Login — ตัวอย่างนี้ยังไม่เปิดลิงก์ฟอร์มจริง

⑤ ประวัติการทดสอบ

    ⚠️ ข้อมูลเก็บเฉพาะใน localStorage ของเบราว์เซอร์ ไม่ส่งไป Make.com, Cloudflare หรือ Data Store จริง ห้ามใช้ข้อมูลลูกค้าจริง
